# Voyz Tour Board 3.0

Доска для сборки туров VOYZ: маршруты, проживание, тайминги, фотографии и отдельная CRM каждого тура. Оригинальный логотип и фирменный салатовый цвет встроены.

## Что умеет

- Расширять карточку: тяните ↔ за правый край. Диапазон 320–1000 пикселей; на телефоне ширина подстраивается под экран. Стрелки клавиатуры меняют ширину, Shift — больший шаг.
- Редактировать прямо внутри карточки название, описание, время и оба блока заметок, включая их названия.
- Добавлять проживание: название и ссылку на отель/карту. «Открыть место» открывает HTTP/HTTPS-ссылку; ссылка также доступна в PDF.
- Переставлять дни и события: перетаскивайте ⠿ или используйте ↑ / ↓. При ровной раскладке каждый ряд начинается слева; учитывается ширина и высота карточек.
- Создавать и изменять стрелки между любыми днями.
- Собирать до 100 туров, до 100 дней в туре и до 100 событий в дне. Вкладки прокручиваются; «Все туры» открывает поиск. Проверено с 20 дополнительными турами. Вместимость зависит также от фото и хранилища устройства.
- Освободить место: «Больше места» скрывает заголовок и даты. «В пути» показывает вертикальную ленту для телефона и планшета.
- Вести клиентов: ФИО, контакт, город вылета, М/Ж, статус, индивидуальная стоимость, предоплата, доплата и заметка. Пол обозначен текстом и цветом. Подсчёты исключают отменённых клиентов.
- Выгружать весь маршрут в PDF, один день в PNG/JPG, тур или всю библиотеку с CRM в JSON. Импорт добавляет копии, сохраняя имеющиеся туры.

## Сохранение и онлайн

Изменения сначала сохраняются на устройстве в IndexedDB; при недоступности используется localStorage. При конфликте вкладок или нехватке места появляется сообщение — скачайте бэкап до закрытия. Копия предыдущего сохранения помогает восстановить данные. Старое сохранение версии 1 не удаляется.

Проект Supabase **Voyz Tour Board** создан в организации **Voyz** (Free, заявленная стоимость создания $0/месяц). Конфигурация браузера содержит только публичный ключ. Для входа нажмите «Онлайн», укажите email своего аккаунта Supabase и откройте ссылку из письма на том устройстве, где работаете. Стандартная почта Supabase ограничена адресами участников организации и частотой отправки. Другим гидам для просмотра не нужен аккаунт.

Онлайн-пространство и исходная местная доска разделены. При первом входе приложение предлагает получить онлайн-туры или перенести местные туры и CRM. Автоматического переноса личных данных нет. Для аккаунта и проекта используется отдельный кеш. После выхода открывается исходная местная доска.

Синхронизация отправляет изменённые туры после местного сохранения. Если другая версия уже сохранена с другого устройства, отправка останавливается; «Сохранить обе версии и обновить» сохраняет местные правки отдельной копией. «Получить обновления» загружает изменения с другого устройства. При возвращении связи выполняется повторная синхронизация.

Кнопка «Поделиться» создаёт ссылку для гидов на актуальную онлайн-версию тура: только просмотр, без клиентов и оплат. Ссылка действует 30 дней; её можно отозвать. Обычные заметки, фотографии и проживание входят в общий маршрут — используйте CRM для личных данных клиента. Отзыв не стирает уже скачанные файлы и копии с чужих устройств.

После первого открытия сайт сохраняет интерфейс для работы без связи. Ранее открытые туры сохраняются на устройстве; общий маршрут также получает отдельную офлайн-копию. Перед поездкой откройте нужные маршруты с интернетом. Новому устройству при первом открытии нужна связь. Очистка данных браузера удаляет местные копии. Скачивайте JSON-бэкап, особенно перед поездкой.

## Локальный запуск

Распакуйте архив целиком и откройте **Открыть Voyz.cmd**. Адрес: http://localhost:4173/. Окно сервера оставьте открытым. Нужен Node.js 18+; на текущем компьютере используется Node из Codex. Установка зависимостей не требуется. Также работает `npm start`.

Без сервера можно открыть dist/index.html в Chrome/Edge. Это отдельное местное хранилище; для полноценного входа и офлайн-сайта используйте HTTPS-версию или localhost. Прежние данные привязаны к браузеру и адресу. Для переноса на новый адрес скачайте «Бэкап всех туров», затем выполните «Импорт».

## Проверки

Проверены расширение/раскладка карточек, сохранение новых полей, 20 вкладок и поиск, ширина экранов 768 и 390, PDF с кликабельной ссылкой проживания. Поля исходного тура, включая фотографии, тайминги и CRM, сравнены с копией до обновления: прежние значения сохранены.

Проверка реальной PostgreSQL прошла: доступ двух владельцев, конфликт версий, удаление/восстановление, публичный маршрут без CRM, отзыв и срок ссылки. Браузерная проверка опубликованного сайта прошла на экранах 390×844 и 768×1024 без горизонтальной прокрутки в режиме «В пути», фотографии загрузились, ошибок в консоли не было. На временном тестовом маршруте проверены реальный анонимный доступ через API, обновление по той же ссылке и отзыв доступа: карточки после отзыва исчезли. Тестовые записи удалены, отсутствие остатков подтверждено.

Вход владельца по настоящему письму на публичном сайте и сохранение исходного майского тура через API подтверждены. В базе один исходный тур с семью днями; сравнение всех 230 узлов JSON с местным бэкапом дало ноль различий (исключены новый идентификатор и настройки вида). Отдельно совпали хеши фотографий. Общая ссылка реального тура открылась без входа и показала семь дней с тремя фотографиями, исключая CRM. Два отдельных физических устройства и длительная ротация сессий не проверялись.
